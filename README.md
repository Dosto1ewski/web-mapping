# web-mapping

A small starter project for Leaflet (HTML + Vanilla JS).

Project path: /Users/anselm/projects/web-mapping

Quick start:

1. Start a local development server:
   - With the VS Code Live Server: Right-click `index.html` -> "Open with Live Server"
   - Or with the included start script (requires Node.js):
     - `npm install` (if needed)
     - `npm run start`

2. Open in the browser: http://localhost:51570

Notes:
- Leaflet is included via CDN (see `index.html`).
- If you prefer a different port, change the `start` script in `package.json`.

Example: The map shows a marker in London on start.
